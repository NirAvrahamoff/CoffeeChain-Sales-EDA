# Data

`coffee_chain_sales.csv` is the [Coffee Chain Sales](https://www.kaggle.com/datasets/amruthayenikonda/coffee-chain-sales-dataset/data) dataset from Kaggle: 1,062 records from October 2012 to August 2015. The Kaggle page does not state how the data was collected.

| Column | Meaning |
|---|---|
| Area Code | Numeric code of the geographic area |
| Cogs | Cost of goods sold |
| DifferenceBetweenActualandTargetProfit | Profit minus target profit (renamed `Profit_vs_target` in the notebook) |
| Date | Record date (month/day/year) |
| Inventory Margin | Inventory level (renamed `Inventory` in the notebook) |
| Margin | Reported margin |
| Market_size | Major Market or Small Market |
| Market | Region: Central, East, South, West |
| Marketing | Marketing expenses |
| Product_line | Beans or Leaves |
| Product_type | Coffee, Espresso, Herbal Tea or Tea |
| Product | One of 13 products |
| Profit | Profit |
| Sales | Sales |
| State | One of 20 US states |
| Target_cogs, Target_margin, Target_profit, Target_sales | Targets for the matching measures (`Target_sales` has a trailing space in the original header) |
| Total_expenses | Total expenses |
| Type | Regular or Decaf |
